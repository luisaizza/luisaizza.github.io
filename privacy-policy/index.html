Política de Privacidade

Última atualização: Março de 2026

O AutoViralTok ("nós", "nosso" ou "aplicativo") respeita a privacidade dos seus usuários. Esta política descreve como coletamos, usamos e protegemos suas informações.

1. Informações que Coletamos

Nosso aplicativo coleta apenas as informações estritamente necessárias para seu funcionamento:

Credenciais de API: Chaves de API do YouTube e TikTok fornecidas voluntariamente por você para conectar suas contas. Essas credenciais são armazenadas localmente no seu dispositivo e nunca são transmitidas para servidores de terceiros além das APIs oficiais do YouTube e TikTok.

Dados de uso: Estatísticas internas de processamento (número de vídeos analisados, cortes gerados, publicações realizadas). Esses dados existem apenas durante a sessão ativa e não são persistidos externamente.

2. Como Usamos as Informações

As credenciais de API são utilizadas exclusivamente para: buscar vídeos públicos na API do YouTube Data v3; publicar conteúdo na sua conta TikTok através da Content Posting API oficial. Nenhuma informação pessoal é vendida, compartilhada ou transferida para terceiros.

3. Armazenamento e Segurança

Todas as credenciais são armazenadas localmente no seu computador (arquivo .env). Vídeos temporários são armazenados na pasta temporária do sistema e deletados após processamento. Nenhum dado é enviado para servidores externos além das APIs oficiais do YouTube e TikTok.

4. APIs de Terceiros

Este aplicativo interage com as seguintes APIs oficiais, cada uma com suas próprias políticas de privacidade:

YouTube Data API v3 — sujeita à Política de Privacidade do Google

TikTok Content Posting API — sujeita à Política de Privacidade do TikTok

5. Seus Direitos

Você pode a qualquer momento: remover suas credenciais de API deletando o arquivo .env; desinstalar o aplicativo e todos os dados locais serão removidos; revogar o acesso do aplicativo diretamente nas configurações de desenvolvedor do YouTube e TikTok.

6. Menores de Idade

Este aplicativo não é destinado a menores de 18 anos. Não coletamos intencionalmente informações de menores.

7. Alterações nesta Política

Podemos atualizar esta política periodicamente. A data de última atualização será sempre indicada no topo da página.

8. Contato

Para dúvidas sobre privacidade, entre em contato pelo email indicado na página do aplicativo no TikTok Developer Portal.
